# Sports Coach Appointment & Video Consultation Platform

A full-stack web application that connects users with sports coaches through appointment booking and real-time video consultations.

## Features

- User Authentication & Authorization
- Coach Profile Management
- Appointment Booking System
- Real-Time Video Calling with WebRTC
- Real-Time Communication using Socket.io
- Payment Integration
- Cloudinary Image Upload
- Search Coaches by Sport or Name
- Responsive User Interface

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- Passport.js
- Socket.io
- WebRTC
- Razorpay
- Cloudinary
- EJS
- JavaScript

## Project Highlights

- Built a complete appointment booking workflow between users and coaches.
- Implemented peer-to-peer video calling using WebRTC.
- Used Socket.io for real-time signaling and communication.
- Integrated Razorpay for appointment payments.
- Implemented secure authentication using Passport.js and sessions.
- Stored and managed application data using MongoDB.
